# ADR-002: Retry receipt submission

**Status:** Accepted

## Routing
**Read when:** Retry receipt submission
**Applies to:** api/*
**Constraint:** Reuse the same request identifier after timeout; do not generate a new key.

## Decision
Reuse the same request identifier after timeout; do not generate a new key.

## Rationale
The receiving system deduplicates by request identifier; changing it creates another receipt.
