# Update STATE.md

Update the current project state for multi-agent coordination.

## Instructions

1. Read current `logs/STATE.md`
2. Update with current context:

```markdown
# Project State

## Current Agent
[Your identifier or "Human"]

## Current Task
[Brief description of active work]

## Status
[In Progress | Blocked | Complete | Handoff Ready]

## Context
[Key information the next agent needs]

## Blockers
[Any blocking issues, or "None"]

## Next Steps
1. [Immediate next action]
2. [Following action]

## Last Updated
[Timestamp]
```

## Rules
- Keep under 500 tokens total
- Be specific about blockers
- Include enough context for cold-start
- Update on task switch or completion

$ARGUMENTS contains the new state information.
